## Build-Verify-Fix Workflow

Follow this 7-step loop on every design task in DESIGN:OS Studio:

1. **Orient (Read first)** — Use session bootstrap context or call {{#if tool:designos_get_document}}{{tool:designos_get_document}}{{/if}}{{#if tool:designos_list_nodes}} and {{tool:designos_list_nodes}}{{/if}} to inspect pages, frames, variables, styles, and components; do not dump the full document.
2. **Plan & Ground** — Plan sections and choose components/tokens via {{#if tool:designos_get_variables}}{{tool:designos_get_variables}}{{/if}}{{#if tool:designos_get_guidelines}} and {{tool:designos_get_guidelines}} (`topic: "design-system"`, `"archetypes"`, or surface guides `"web-app"`, `"mobile-app"`, `"landing-page"`, `"slides"`, `"table"`){{/if}}. Place new top-level frames beside existing frames on the active page — never stack at `(0, 0)`.
{{#if write_tools}}
3. **Build in sections** — {{#if tool:designos_apply_spec}}Build one section per call ({{#if tool:designos_apply_batch}}{{tool:designos_apply_batch}} / {{/if}}{{tool:designos_apply_spec}}).{{#if tool:designos_set_in_progress}} Put `in_progress: true` in the root node's spec.{{/if}} Use components as instances (`kind: "instance"`), tokens as `var:` / `style:` references, and auto layout (`layout`) by default.{{/if}}{{#unless tool:designos_apply_spec}}{{#if tool:designos_apply_batch}}Build one section per {{tool:designos_apply_batch}} call.{{#if tool:designos_set_in_progress}} End the batch with a `set_in_progress` op (`value: true`) on the root frame.{{/if}} Use components as instances, tokens as `var:` / `style:` references, and auto layout by default.{{/if}}{{#unless tool:designos_apply_batch}}Build each section using enabled write tools ({{#if tool:designos_create_node}}{{tool:designos_create_node}}{{/if}}{{#if tool:designos_update_node}}, {{tool:designos_update_node}}{{/if}}){{#if tool:designos_set_in_progress}}, flag the root frame with {{tool:designos_set_in_progress}} (`node_ids: [root]`, `value: true`),{{/if}} and use auto layout by default.{{/unless}}{{/unless}}
4. **Verify (`issues` + screenshot)** — Check the per-call `issues` block (`issues: {total, new_in_this_call, items}`) first; then inspect a screenshot of the finished section: {{#if tool:designos_render_png}}Call {{tool:designos_render_png}} on the finished frame (default scale, long edge <= 1024) or use `diff_image` and inspect the PNG for visual hierarchy, alignment, clipping, and contrast.{{/if}}{{#unless tool:designos_render_png}}Inspect the frame hierarchy{{#if tool:designos_get_node}} with {{tool:designos_get_node}}{{/if}} for visual hierarchy, alignment, clipping, and contrast.{{/unless}}
5. **Fix in place** — Fix findings in place with update ops ({{#if tool:designos_update_node}}{{tool:designos_update_node}}{{/if}}{{#if tool:designos_apply_batch}} or {{tool:designos_apply_batch}} `update`{{/if}}); never delete and rebuild a section to fix it.
6. **Clear `in_progress` & audit** — {{#if tool:designos_set_in_progress}}Clear `in_progress` ({{tool:designos_set_in_progress}} with `node_ids: [root]`, `value: false`) when done{{/if}}{{#if tool:designos_lint}}{{#if tool:designos_set_in_progress}}, and call{{/if}}{{#unless tool:designos_set_in_progress}}Call{{/unless}} {{tool:designos_lint}} (`preset: "agent"`, `"strict"`, or `"marketing"`) to resolve remaining errors{{/if}}{{#unless tool:designos_set_in_progress}}{{#unless tool:designos_lint}}Re-check the finished section against step 4{{/unless}}{{/unless}}.
{{/if}}
7. **Errors & retries** — Follow `next_step`; resend `corrected_example` (or `valid_options`) when `safe_to_retry` is `true`; re-read state when `safe_to_retry` is `false`{{#if write_tools}}; pass `idempotency_key` on writes{{/if}}{{#unless write_tools}}{{#if tool:designos_lint}}, and run {{tool:designos_lint}} (`preset: "agent"`) when auditing screens{{/if}}{{/unless}}.
