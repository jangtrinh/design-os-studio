## Ledger
- FACT: import made a default `SlotPropConfig` entry for a preferred-only slot (rest_import.rs resolve_swaps `or_default()`); export wrote `slotPropConfig` for every entry (fig_export.rs Slot arm).
- FACT: `export_fig` exported only page children and library_page children; guids are allocated for every node, so a detached preferred component's guid was written but the node was not.
- FACT: `expand_instance` cleared `component.props` but not `slot_configs`.
- FACT: Untitled UI kit clone scan: 119748 nodeChanges, 12215 prop defs, 0 SLOT defs, 0 slotPropConfig, 0 isSlot. No slots.
- ASSUMPTION: an old .designos file holding a real empty config (flag did not exist) now omits it on re-export. Indistinguishable from the bug; accepted.

## Root cause and fix
1. Absent vs empty config: new `SlotPropConfig.empty_config_written` (node.rs, `skip_serializing_if = is_false`, serde default, so old files load unchanged and the key stays absent). Import sets it only when the file wrote `slotPropConfig: {}` (rest_import.rs parse_component_props). Export writes `slotPropConfig` only when `SlotPropConfig::has_settings()` (any setting, unmapped key, or the flag) (fig_export.rs Slot arm).
2. Detached preferred: `detached_slot_preferred` + `is_attached` (fig_export.rs) find preferred components on no page or library page, held by attached nodes; they are exported on the Internal Only Canvas, which is created when any exist.
3. `expand_instance` now also does `n.component.slot_configs.clear()` (rest_import.rs).

## Draft PR body
Fixes #473.

- A slot that lists only preferred components no longer gets an empty `slotPropConfig` when the file is saved as .fig. A config the source wrote empty is still written back.
- A component that only a slot's preferred list keeps alive, and that sits on no page, is now saved on the internal canvas, so the preferred list is no longer emptied on reopen.
- Nested component copies inside an instance no longer carry the definition's slot settings.

Old .designos files load unchanged. Tested with synthetic files; the Untitled UI kit has no slots.
