This document describes the Interactive State Machine, the 8 interaction flows 1:1 with Figma (`UF-01..UF-08`), the unified Phosphor Icons system (`DIR-19` / `US-14`), the native Chat UI wrapped directly over the PTY terminal shell (`Claude Code` / `Codex` / `Antigravity CLI`, `DIR-21` / `US-15`), the Figma UI3 standard shortcuts and the screen transition flow between `S01..S13` in **`design`:os studio**.

## 1. Screen Navigation State Machine (`S01..S13`)

```mermaid
stateDiagram-v2
    [*] --> S04_Home: Launch / Click Home Icon on S10 Tab Strip
```

## 2. Dual-Layer Auto-Update State Machine (`S09`)

```mermaid
stateDiagram-v2
    [*] --> Idle
    Idle --> Checking: Manual Check / Startup Timer / CLI "designos update"
    Checking --> UpToDate: local_version == manifest.version
    Checking --> UpdateAvailable: local_version < manifest.version
    UpdateAvailable --> Downloading: Auto-download or Click "Download Update"
    Downloading --> VerifyingSha256: Download 100% (.staged written)
    VerifyingSha256 --> StagedReadyToRestart: sha256(.staged) == manifest.sha256
    VerifyingSha256 --> RolledBack: sha256 mismatch (delete .staged)
    StagedReadyToRestart --> Applied: Atomic swap (current -> .bak, .staged -> current)
    Applied --> RolledBack: Startup health-check fails or User clicks "Rollback"
```
