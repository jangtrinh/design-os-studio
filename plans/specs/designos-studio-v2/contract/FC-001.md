## 1. Outcome

Users opening **`design`:os studio** can manage projects on the Figma UI3-standard Home screen (`S04`); open and switch instantly between several parallel project tabs on the **Desktop Tab Strip (`36px`, `S10`)** with fully independent state; design directly on a 1:1 standard v106 `.fig` Canvas with 17 node kinds and a 2D CSS Grid (`S01`); use the full Typography 3-tab, Actions `Cmd+K`, Zoom/View, Color/Variables Picker and Dev Mode dialogs (`S05..S08`); work with the **`Agents` Left Side Panel (`S13`, `DIR-17`, `DIR-21`)** as a native Chat UI wrapped directly over the live PTY terminal shell of `Claude Code (claude)`, `Codex (codex)`, `Antigravity CLI (agy)` together with 6 Figma AI actions with `<50ms` Live Hot-Apply (`S11`, `S03`); read/review the full Spec Format v2 package across 5 roles together with the **5-Pillar Quantitative Figma Parity Meter (`S02`, `S12`)** scorecard; install easily on all 3 operating systems `macOS` (`.dmg`/`.app`), `Windows` (`-setup.exe`/`install.ps1`) and `Linux` (`.deb`/`install.sh`) (`DIR-22`) and receive safe automatic updates through Dual-Layer Auto-Update (`S09`); experience a **100% unified Phosphor Icons system (`https://phosphoricons.com/`, `DIR-19`, `US-14`)**; and run screenshot verification entirely in the background (`with_active(false)`).
