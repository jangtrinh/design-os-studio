## 1. User Story
As a **Product Designer & UI Architect**, I want to open/write standard v106 binary `.fig` files directly and use 2D CSS Grid layout (`fr`, `px`, `auto`, `col_span`, `row_span`), so that I can work 1:1 with the Figma ecosystem and export/import `.spec.json` designs without data loss.

## 2. Flow
- Entry condition: The user has a document open on the Canvas screen `S01` or selects a Spec package in `S02`.
- Main flow: 1. Open or import a v106 `.fig` / `.spec.json` file. 2. Select a Frame and turn on `LayoutDirection::Grid` with a `1fr 2fr` or `px` column/row setup. 3. Click **Save .fig** or **Export .spec.json** to save the result losslessly.

## 3. Data and rules

| ID | Rule | Source |
|---|---|---|
| **BR-01** | Every unknown binary field in the Kiwi v106 container must be kept as-is in `raw_fields` on `.fig` round-trip. | [contract](../contract/FC-001.md) D1 |
| **BR-05** | Every Frame on the Canvas can be exported to `.spec.json` (`NodeSpec`) or applied back from `.spec.json` into the open page with 1 undoable command. | [contract](../contract/FC-001.md) D5 |

## 4. Acceptance Criteria

| ID | Given | When | Then | Scenario |
|---|---|---|---|---|
| AC-01 | A standard v106 `.fig` file containing Auto-Layout nodes and extended fields | The user opens and re-saves the `.fig` file | The whole node tree, colour variables and `raw_fields` are 100% preserved with no byte lost. | SCN-01-01 |
| AC-02 | A Frame in `LayoutDirection::Grid` mode with `1fr`, `2fr` columns and a child with `col_span = 2` | The system computes the `relayout_subtree` layout | Child cells are aligned exactly on the 2D grid, with column/row gaps and multi-cell spans supported. | SCN-01-02 |
| AC-03 | The open Spec package has a declarative `.spec.json` design | The user clicks `Apply Spec to Canvas` | The `NodeSpec` tree is built into real Frames on the Canvas and automatically zoomed to fit the viewport. | SCN-01-03 |

## 5. Edge cases
- Empty (`empty`): When the Canvas page has no Frame yet, show a 1-action hint `Apply Spec to Canvas` or create a new Frame.
- Error (`error`): When a `.spec.json` or `.fig` file is structurally corrupt, show a toast naming the decode error and keep the current document state.
- Loading (`loading`): Show Kiwi chunk loading progress when opening a large `.fig` file.
