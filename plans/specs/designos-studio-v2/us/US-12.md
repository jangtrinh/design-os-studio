## 1. User Story
As a **Product Owner, Systems Designer or AI Coding Agent** working in **`design`:os studio**, I want a **5-Pillar Quantitative 1:1 Figma Parity Meter & Live Telemetry Scorecard (`S12` / `scripts/figma_parity_meter.py` / `research/parity-scorecard.json` / CLI `designos --parity-report`)**, so that I always know the exact `%` matched with Figma Desktop (`126.9.13`), the `%` score of each technical pillar (`P1..P5`), and a detailed list of every remaining item needed to reach `100%`, without subjective self-scoring.

## 2. Flow
- Entry condition: The user or an AI agent runs `python3 scripts/figma_parity_meter.py`, runs `designos --parity-report`, or opens the Spec Driven v2 Reader (`S02` / `S12`).
- Main flow: 1. The system automatically compares the Figma reverse-engineering evidence package (`research/kiwi-schema-diff.json`, `figma-rea-report.md`, `VSF - PCP.fig` `155,297` nodes / `203` fields) against the current Rust source (`crates/*`) across 5 weighted pillars (`P1: 25%`, `P2: 20%`, `P3: 20%`, `P4: 20%`, `P5: 15%`). 2. The system computes the overall `overall_parity_pct` score and its complement `remaining_gap_pct = 100.0 - overall_parity_pct` and writes them to `research/parity-scorecard.json` / the CLI table (`--parity-report`). 3. On the Spec Reader v2 screen (`S02` / `S12`), the user views the **Figma 1:1 Parity Meter** card and each pillar's progress bar, and clicks `Copy Parity Report for AI` to send it straight to the PTY Agent Terminal (`S03`).

## 3. Data and rules

| ID | Rule | Source |
|---|---|---|
| **BR-19** | **5-Pillar Quantitative 1:1 Figma Parity Formula (`D14`)**: The total $\text{Total Figma Parity (\%)} = 0.25 \cdot P_1 + 0.20 \cdot P_2 + 0.20 \cdot P_3 + 0.20 \cdot P_4 + 0.15 \cdot P_5$ and $\Delta_{\text{to 100\%}} = 100\% - \text{Total Figma Parity (\%)}$ are computed 100% automatically from real audit data (`P1` `.fig` v106 Kiwi 203 fields & `155,297` nodes; `P2` 68 menus & shortcuts; `P3` 17×5 = 85 element interaction checkpoints; `P4` 14 UI3 surfaces + `ui-contract.md`; `P5` 15 AI Agent & PTY Core checkpoints); subjective self-assigned scores are forbidden. | [contract](../contract/FC-001.md) D14 |

## 5. Edge cases
- No `parity-scorecard.json` file yet (`empty`): Show an empty state with a default scorecard synthesised from the loaded model and a hint to run `python3 scripts/figma_parity_meter.py`.
- Recomputing the scorecard (`loading`): Show a `Computing 5-Pillar Parity...` badge without freezing the 120fps render thread.
- Corrupt JSON file (`error`): Show a `#F59E0B` `STALE SCORECARD` warning and keep the last valid scorecard version.
