## 1. User Story
As a **Product Designer, Systems Architect and Developer**, I want to work on multiple projects at once through the **Figma UI3 Desktop Tab Strip (`36px`, `S10`)** with each project tab's state fully isolated (`Document`, `History` Undo/Redo, `Page`, `Selection`, `View` Zoom/Pan, `Dev Mode`, `file_path`) and the brand always shown correctly as **`design`:os studio** (all lowercase, **`design`** in bold, `:os studio` in lowercase), so that I can switch instantly between multiple `.fig`, `.spec.json`, `FigJam` and `Slides` files without losing working context.

## 2. Flow
- Entry condition: The user is on the Home screen (`S04`) or the Canvas editor (`S01`) of **`design`:os studio**.
- Main flow: 1. Click a project card in Home (`S04`), click the `+` button on the **Desktop Tab Strip (`36px`, `S10`)**, or press `Cmd+T` to open a new project in an independent `ProjectTab`. 2. Switch between the `Home` button and the open project tabs with the mouse or shortcuts (`Ctrl+Tab` / `Cmd+Shift+]`, `Cmd+1..9`); each tab instantly restores its own `Document`, `History` stack (Undo/Redo), `Page`, `Selection`, `Zoom/Pan` level and `Dev Mode`. 3. Right-click a tab to open the context menu (`Duplicate tab`, `Pin/Unpin tab`, `Close other tabs`) or press `×` / `Cmd+W` to close the tab.

## 4. Acceptance Criteria

| ID | Given | When | Then | Scenario |
|---|---|---|---|---|
| AC-01 | The user has the Desktop Tab Strip (`36px`, `S10`) and Home screen (`S04`) open | Check the brand label and create/open multiple project tabs (`Design`, `FigJam`, `Slides`, `Specs`) with the `+` button, `Cmd+T` or from Home | The brand always shows lowercase **`design`:os studio** (**`design`** in bold `700`), and the tab strip shows the `Home` button plus project tabs with file-type badges, a `•` dot when `dirty`, a `Pin` icon, a `×` close button and a `+` button. | SCN-10-01 |
| AC-02 | Two or more project tabs (`Tab A` and `Tab B`) are open at once with different edits, node selections, pages and zoom/pan | The user switches between `Tab A` and `Tab B` (by mouse, `Ctrl+Tab`, `Cmd+Shift+]` or `Cmd+1..9`) and performs `Undo`/`Redo` | Each tab keeps a fully independent `Document`, `History` stack (`Tab A`'s `Undo`/`Redo` does not affect `Tab B`), `Page`, `Selection`, `View` (`zoom`/`pan`) and `Dev Mode` state. | SCN-10-02 |
| AC-03 | The user right-clicks a project tab or closes a tab (`×` / `Cmd+W`) | Choose `Duplicate tab`, `Pin/Unpin tab`, `Close other tabs` or close a pinned / unsaved tab | `Duplicate tab` creates an independent copy of the project; a `Pinned` tab locks its `×` close button to prevent accidental closing; `Close other tabs` keeps pinned tabs and the current tab. | SCN-10-03 |

## 5. Edge cases
- Empty (`empty`): When all open project tabs are closed, automatically switch to the `Home` tab (`S04`) or keep at least 1 empty project tab (`Untitled`) without quitting the app.
- Error (`error`): When opening a `.fig` file path in a new tab but the file does not exist or is corrupt, show an error toast and keep the previously active tab.
- Pinned / Locked (`disabled`): When a project tab is `Pinned`, hide the `×` button on the tab and disable direct `Cmd+W` until the user chooses `Unpin tab`.
