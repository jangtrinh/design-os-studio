## 1. User Story
As a **Product Designer**, I want to interact directly on the Canvas (`S01`) with all 17 node kinds (`Frame`, `Section`, `Group`, `Component`, `ComponentSet`, `Instance`, `Rectangle`, `Ellipse`, `Polygon`, `Star`, `Line`, `Vector`, `BooleanOp`, `Text`, `Slice`, `Sticky`, `Connector`) with 1:1 Figma behaviour, including `#0D99FF` / `#9747FF` hover outlines, `double-click` drill-down, 8 resize handles, corner-radius handles, pink padding/gap handles, `Alt` distance guides and the dotted 2D CSS Grid overlay, so that design work stays smooth at 120fps.

## 2. Flow
- Entry condition: The user has a document open on the Canvas (`S01`) with the `Move (V)` tool.
- Main flow: 1. Hover over any element of the 17 node kinds to see the hover outline (`#0D99FF`, or `#9747FF` for Component/Instance). 2. Click to select or `double-click` to drill into a child group/frame or open the in-place text/vector editor. 3. Drag the 8 resize handles, the 4 inner corner-radius dots, the Auto-Layout padding/gap handles or the 2D CSS Grid column/row dividers.

## 3. Data and rules

| ID | Rule | Source |
|---|---|---|
| **BR-01** | When a Frame has `LayoutDirection::Grid` on, the layout algorithm splits `fr`, `px`, `auto` tracks exactly and applies `col_span`, `row_span` to each child. | [contract](../contract/FC-001.md) D1 |
| **BR-09** | All 17 `NodeKind` kinds must respond correctly to hit-testing and draw the `#0D99FF` selection outline (`#9747FF` for Component/Instance), 8 white square handles with blue borders, 4 round corner-radius handles, pink padding/gap handles, the red `Alt` measurement and the dotted 2D Grid with track labels on the Canvas. | [contract](../contract/FC-001.md) D1, D6 |

## 4. Acceptance Criteria

| ID | Given | When | Then | Scenario |
|---|---|---|---|---|
| AC-01 | A Canvas page containing all 17 node kinds nested several levels deep | The user hovers, single-clicks, `Cmd+click`s or `double-click`s repeatedly | The system highlights the correct `#0D99FF`/`#9747FF` hover outline, drills down parent → child one level per `double-click`, and activates direct text/vector editing at the final leaf. | SCN-06-01 |
| AC-02 | A `Rectangle`, `Frame` or `Auto-Layout` node is selected on the Canvas | The user drags a resize handle, corner-radius dot or the pink `padding` / `gap` bar | The size, corner radius (`corner_radius`) or Auto-Layout spacing updates live in real time with a floating value label and `Undo/Redo` support. | SCN-06-02 |
| AC-03 | A Frame with `2D CSS Grid` layout (`LayoutDirection::Grid`) is selected on the Canvas | The user looks at and drags to resize cells on the Canvas | The Canvas shows dotted grid lines between `cells`, column/row header pill labels (`1fr`, `2fr`, `auto`, `px`) and updates the 2D layout instantly. | SCN-06-03 |

## 5. Edge cases
- Empty (`empty`): When clicking empty space outside a Frame, deselect all nodes and switch the Right Inspector to `Page` mode (`#1E1E1E` background, `Styles`, `Export`).
- Error / Limits (`error`): When the user drags a size or corner radius beyond the geometric limit (`r > min(w, h)/2`), automatically `clamp` it to the valid range.
- Locked (`disabled`): Nodes with `locked = true` skip normal Canvas hit-testing and can only be selected from the `Layers` tree, shown with a lock icon.
