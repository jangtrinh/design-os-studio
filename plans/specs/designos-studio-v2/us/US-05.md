## 1. User Story
As a **UI Designer & Frontend Engineer**, I want to use the full Figma UI3 standard Chrome, Settings, Menus and Popovers (`S05..S08`), including the 3-tab `Type settings` dialog (`Basic | Details | Variable`), the `Actions (Cmd+K)` bar docked above the bottom toolbar, the `Zoom/View` menu with a `%` input, the `Color Picker` (`HEX/RGB/CSS/HSL/HSB`), the `Scoped Variables Picker` and `Dev Mode (</>)` Box Model + 5-language code generation, so that I can fine-tune designs and hand off code exactly 1:1.

## 2. Flow
- Entry condition: The user has a document open in Studio (`S01`) and opens the matching popovers/menus (`S05..S08`).
- Main flow: 1. Click the `⋯` icon in the Typography section to open `Type settings` (`Basic | Details | Variable`) (`S05`). 2. Click the `Actions (Cmd+K)` button on the bottom toolbar to open the bottom-docked `Cmd+K` dialog (`S06`). 3. Click `Zoom % ⌄` in the top-right corner to enter a zoom level or toggle `Pixel grid`, `Rulers`, `Layout grids` (`S05`). 4. Open the `Color Picker` or `Scoped Variables Picker` (`S08`) and switch to `Dev Mode (</>)` (`S07`) to see the Box Model with CSS/Tailwind/SwiftUI/Compose/React code.

## 5. Edge cases
- Empty (`empty`): When the document has no Variable matching the scope (`matches_scope`), the `Scoped Variables Picker` shows an empty message with a `+ Create Variable` button.
- Error (`error`): When the user enters an invalid zoom `%` or `HEX` colour, the input automatically restores the previous valid value without causing a render error.
- Disabled (`disabled`): `Type settings` options are automatically disabled when the selected node has no text or is locked (`locked = true`).
