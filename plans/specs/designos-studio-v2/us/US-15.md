## 1. User Story
As a **Product Designer, Systems Architect and AI Engineer**, I want the Agentic surface (`RailItem::Agents`, `S13`) in **`design`:os studio** to work purely as a **native Chat UI wrapped directly over the live PTY terminal shell** of **Claude Code (`claude`)**, **Codex (`codex`)** and **Antigravity CLI (`agy`)** — with a 1-click quick selector (`Claude Code | Codex | Antigravity`), User/Assistant chat bubbles (`AgentChatTurn` / `AgentChatRole`) streaming stdout with ANSI control codes fully stripped (`sync_chat_from_pty` + `strip_ansi_codes`), automatic detection of inline `NodeSpec` blocks with a button/badge to apply them to the Canvas (`1-step Undo`), Selection + Pin-Comment (`+`) context attachment and instant switching between the clean Chat thread and the raw VT100 Terminal screen — so that I can chat with and drive the CLI agents already logged in on my machine directly, without any paid external API key.

## 2. Flow
- Entry condition: The user opens a project in **`design`:os studio** and clicks the **`Agents` (`✦`)** icon in second position on the Left Rail (`RailItem::Agents`, opening `S13` at `240px–320px` wide).
- Main flow: 1. At the top of the `Agents` panel (`S13`), the user picks a runtime on the 1-click pill bar **`Claude Code | Codex | Antigravity`**; the system activates or starts the matching `portable-pty` + `vt100` session (`claude`, `codex` or `agy`) with the full set of `$DESIGNOS_*` environment variables (`$DESIGNOS_BIN`, `$DESIGNOS_FILE`, `$DESIGNOS_MCP_BIN`, `$DESIGNOS_LIVE_SPEC`, `$DESIGNOS_SELECTION_JSON`) and no paid external API key required. 2. The user can click the `+` button in the `"Ask for changes"` input to attach the current Canvas Selection + Pin-Comment context, type a request and press `Enter` (or the `↑` send arrow); the system creates an `AgentChatTurn` with `AgentChatRole::User`, writes the command line into the selected shell's PTY master and creates a streaming `AgentChatRole::Assistant` bubble. 3. On every frame, `sync_chat_from_pty` reads the new data from the PTY tab's `pty_log`, strips all ANSI CSI/OSC escape sequences via `strip_ansi_codes` and updates the `Assistant` bubble content live in real time. 4. When the `Assistant` output contains a valid `NodeSpec` JSON block, the chat bubble shows an inline `NodeSpec` badge (`Apply to Canvas` / `Applied`) to apply the design to the Canvas in 1 `History` step (`Cmd+Z`), and the user can toggle instantly between **Chat Thread View** and the **Raw VT100 Terminal (`>_ Terminal`)** screen on the same PTY session.

## 5. Edge cases
- CLI binary not installed on the machine (`empty` / fallback): When `claude`, `codex` or `agy` is not in `$PATH`, the PTY tab automatically falls back to an interactive `$SHELL` with a short guidance message in the `Assistant` bubble, without hanging the UI.
- PTY output containing complex ANSI escape sequences (`CSI`, `OSC`, cursor control): `strip_ansi_codes` fully removes the control sequences before display in the Chat bubble, while the `>_ Terminal` screen keeps the TrueColor VT100 palette.
- A partially streamed `NodeSpec` JSON string (`loading`): The `Assistant` bubble shows a streaming state and only activates the `NodeSpec` badge once the JSON block has validly closed its brackets.
