## 1. User Story
As a **Product Designer, Systems Architect and AI Engineer**, I want **`design`:os studio** to integrate the full **1:1 Figma AI Agent Suite (`Actions ⌘K` `S06`, `Agents` Left Rail `S11`, and the Canvas Context Menu AI)** running directly on the **Native PTY Terminal Core (`S03`)** with 5 first-class CLI Runtimes (`Claude Code` `claude`, `Codex` `codex`, `Antigravity` `agy`, `Grok` `grok`, `$SHELL`), **Live Hot-Apply (`<50ms`)**, **1-Step Undo (`Cmd+Z`)** and every Figma `126.9.13` feature gap closed (Gaps A–F), so that I can trigger the 6 Figma AI actions in 1 click while reusing my existing CLI Agent login session directly, with no intermediary API token cost.

## 2. Flow
- Entry condition: The user has a project tab open in **`design`:os studio** (`S01`/`S10`) or opens the `Agents` (`S11`) / `Actions (⌘K)` (`S06`) / `PTY Terminal` (`S03`) pane.
- Main flow: 1. In the `Agents` pane (`S11`) or the `PTY Terminal` dock (`S03`), the user chooses 1 of the **5 CLI Runtime Presets** (`Claude Code`, `Codex`, `Antigravity`, `Grok`, `$SHELL`) labelled `INSTALLED` / `ACTIVE PTY`; the system starts a `portable-pty` session and automatically injects `$DESIGNOS_BIN`, `$DESIGNOS_FILE`, `$DESIGNOS_MCP_BIN`, `$DESIGNOS_LIVE_SPEC`, `$DESIGNOS_SELECTION_JSON`. 2. The user clicks 1 of the **6 Figma AI Actions** (`Make Design / First Draft`, `Make Prototype`, `Rename Layers`, `Rewrite / Translate / Shorten Text`, `Populate Realistic Data`, `Design Gate Audit & Auto-Fix`) from `Actions ⌘K` (`S06`), the `Agents` Rail (`S11`) or the Canvas right-click menu; the system applies the change on the Canvas in 1 `History` step and pipes a structured prompt + selection context to the active PTY session (`A1`). 3. When the CLI Agent writes a `.spec.json` patch to `$DESIGNOS_LIVE_SPEC` or emits a `DESIGNOS_SPEC_JSON:` stream, the watcher hot-applies it to the Canvas in `<50ms` with a Diff Toast and merges it into a single `Undo` step (`Cmd+Z`) (`A2`).

## 5. Edge cases
- Empty / CLI not installed (`empty`): When the workstation does not have a specific binary installed (e.g. `agy` or `grok`), show a `FALLBACK -> $SHELL` label and open an interactive shell with the `$DESIGNOS_*` environment variables preloaded plus a login command hint, without a UI-blocking error.
- JSON syntax error (`error`): When the `$DESIGNOS_LIVE_SPEC` file is half-written or has invalid JSON syntax, skip that read, keep the `Document` and `History` stack unchanged and show a thin `#F24822` warning on the Diff Toast.
- Locked / No selection (`disabled`): When the user calls `Rename Layers` or `Rewrite Text` with no node selected, automatically apply it to the top-level Frame on the current page or show a clear hint to select a node.
