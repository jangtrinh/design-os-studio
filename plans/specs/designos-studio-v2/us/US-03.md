## 1. User Story
As an **AI Product Engineer**, I want to run `claude`, `codex`, `gemini` or `$SHELL` directly in the integrated PTY Terminal window (`S03`) and quickly send `Copy for AI` citations from the Spec Reader to the Terminal, so that the AI agent can fix the spec or update the design on the Canvas immediately.

## 2. Flow
- Entry condition: The user has copied an item with `Copy for AI` in `S02` or has a Frame selected on `S01`.
- Main flow: 1. Open the PTY Agent Terminal pane (`S03`). 2. Choose an agent preset (`Claude`, `Codex`, `Gemini`, `Shell`). 3. Paste or send the `Copy for AI` citation block into the running PTY session. 4. The agent updates the `.spec.json` or Spec docs and the user clicks `Apply Spec to Canvas` to sync.

## 4. Acceptance Criteria

| ID | Given | When | Then | Scenario |
|---|---|---|---|---|
| AC-01 | The user opens the Terminal toolbar or shortcut in Studio | Start a new PTY session with the `claude` or `codex` preset | The PTY process starts without blocking the 120fps UI render thread and shows full ANSI output. | SCN-03-01 |
| AC-02 | The user has just clicked `Copy for AI` on an AC row in `S02` | The user switches to Terminal `S03` and pastes the request | The citation, with full file path, line numbers and US/AC context, is passed to the Agent intact. | SCN-03-02 |
| AC-03 | The Agent has finished editing the `.spec.json` file or docs in `plans/specs/` | The user clicks refresh or `Apply Spec to Canvas` | The Spec Reader shows the new content immediately and the Canvas builds the newly generated Frame structure correctly. | SCN-03-03 |

## 5. Edge cases
- Empty (`empty`): When no PTY session is running yet, show an empty state with quick-start buttons `Start Claude`, `Start Codex`, `Open Shell`.
- Error (`error`): When the agent's CLI command is not in `PATH`, show a clear error naming the missing binary and suggest switching to the default `$SHELL`.
- Disconnected / exited (`disabled`): When the child process ends, show the `exit code` and a `Restart Session` button.
