## 1. User Story
As a **Product Designer & Team Lead**, I want to manage all design documents on a Figma UI3 standard Home screen (`S04`) with `Recents`, `Drafts`, `All folders`, `Resources / Templates`, `Starred`, `Trash` sections, a file-type filter, sorting, Grid/List toggle, file-type badges and a right-click context menu, so that I can organise `.fig` and `.spec.json` projects exactly like Figma Desktop.

## 2. Flow
- Entry condition: The user clicks the Home icon in the top-left corner or starts Studio in File Browser mode (`S04`).
- Main flow: 1. Choose a left navigation section (`Recents`, `Drafts`, `All folders`, `Resources`, `Starred`, `Trash`). 2. Search by name, filter by type (`Design`, `FigJam`, `Slides`, `Spec v2`) or change the sort order (`Last modified`, `Alphabetical`, `Date created`). 3. Double-click a file card to open it on the Canvas, or right-click to `Duplicate`, `Rename`, `Star`, `Export .fig`, `Move to Trash` / `Restore`.

## 4. Acceptance Criteria

| ID | Given | When | Then | Scenario |
|---|---|---|---|---|
| AC-01 | The user is on Home screen `S04` containing `.fig`, FigJam, Slides and Spec files | The user switches between `Drafts`, `All folders`, `Resources`, `Starred` and `Trash` | The file list updates instantly for the right section, showing canvas thumbnails and file-type badges in Figma UI3 colours. | SCN-04-01 |
| AC-02 | The user types a search term or chooses a file-type filter and sort order | The user filters `Design files` and sorts `Alphabetical` | The file grid shows only matching documents and switches smoothly between `Grid` and `List` modes. | SCN-04-02 |
| AC-03 | The user right-clicks a file card in `Drafts` or `Trash` | Choose `Star`, `Duplicate`, `Rename`, `Move to Trash` or `Restore` | The file state updates in memory immediately and is reflected correctly in the `Starred` or `Trash` section. | SCN-04-03 |

## 5. Edge cases
- Empty (`empty`): When the `Starred` or `Trash` section has no documents yet, show an empty-state card with a `+ New Design File` or `Import .fig` action button.
- Error (`error`): When the user imports a corrupt `.fig` file from the `Import` button, show a decode error banner at the top of the Home screen without losing the existing file list.
- Loading (`loading`): Show a `skeleton thumbnail` while rendering thumbnails for large `.fig` files.
