## 1. User Story
As a **Product Owner, Product Designer and Systems Engineer**, I want the whole **`design`:os studio** icon system (`crate::icons::Icon`) to consistently use the **official Phosphor Icons set (`https://phosphoricons.com/`, `@phosphor-icons/core` `viewBox="0 0 256 256"`, `fill="currentColor"`)** bundled at `crates/designos-app/assets/icons/phosphor/` and rendered through a `resvg` cache snapped to the DPR pixel grid (`DPR-aware pixel-snapped texture cache`) on all screens `S01..S13` (Left Rail `48px`, Left Side Panels `Layers`/`Agents`/`Assets`, Bottom Floating Toolbar & Contextual Sub-Toolbar, Top Multi-Tab Bar `36px`, Right Inspector `Design`/`Prototype`/`Dev Mode`, `Actions Cmd+K`, Menus, Popovers, Home Screen and the `PRODUCT:OS Spec Driven v2` Reader), so that the UI is fully visually consistent, with no mixing of icon families or scattered hand-drawn strokes, while keeping the `Icon::Logo` brand mark.

## 2. Flow
- Entry condition: **`design`:os studio** starts and renders any surface among the 13 standard screens (`S01..S13`) on a standard (`1.0x`) or Retina/HiDPI (`2.0x+`) display.
- Main flow: 1. When any UI component calls `icons::paint(painter, icon, center, size, color)` or `icons::image(ctx, icon, size, color)`, `crates/designos-app/src/icons.rs` maps the `Icon` variant to a standard Phosphor SVG file (`viewBox="0 0 256 256"`, `fill="currentColor"`) embedded from `crates/designos-app/assets/icons/phosphor/*.svg` (except `Icon::Logo`, which keeps the **`design`:os studio** brand shape). 2. The system computes the physical pixel size `px = (size * pixels_per_point).round()`, rasterises the SVG with `resvg` using `TextureOptions::LINEAR`, stores it in the `SVG_CACHE` keyed by `(Icon, px)` and aligns draw coordinates to `1.0 / pixels_per_point` steps so every icon is perfectly sharp at 120fps. 3. All icons on the Left Rail, Layers, Agents (`S13`), Assets, Bottom Toolbar, Right Inspector, `Actions (⌘K)`, Menus, Popovers, Home (`S04`) and Spec Reader v2 (`S02`/`S12`) share the same Phosphor Icons geometry, stroke weight and corner rounding.

## 5. Edge cases
- Fractional DPI scale or display change (`loading` / `focus`): When the window moves between a `1.0x` display and a Retina `2.0x` display, the `(Icon, physical_px)` cache key automatically picks the correct physical raster size without blurring or pixelation.
- Very small icons (`10px–12px` on layer/tab badges): Still guarantee visible pixels `> 0` and a clearly recognisable shape thanks to the Phosphor Icons standard `256×256` viewBox.
- The `Icon::Logo` brand mark (`disabled` / intentional exception): Keep the **`design`:os studio** brand vector shape, never overridden by a generic icon.
