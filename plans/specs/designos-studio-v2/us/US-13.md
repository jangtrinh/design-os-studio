## 1. User Story
As a **Product Owner, Product Designer and AI Engineer**, I want the **`Agents` (`✦`)** item to sit second on the Left Rail (right below `File`) and open directly inside the **Left Side Panel (`240px–320px`, `S13`)**, 1:1 with Figma UI3, with a VT100 PTY Terminal window (`claude`, `codex`, `grok`, `$SHELL`) that can be toggled inside the side panel or expanded into the bottom dock (`[↗]`), while all **9 visual deltas (`Visual Deltas 1..9`)** and **5 end-to-end user interaction flows (`UF-01..UF-05`)** are standardised 1:1 with Figma Desktop `126.9.13`.

## 2. Flow
- Entry condition: The user has a document open in **`design`:os studio** (`S01` / `S10`).
- Main flow: 1. The user clicks the `Agents` icon (`✦`, second position right below `File` on the Left Rail); the Left Side Panel (`240px–320px`, `S13`) switches to the Figma UI3 `Agents` view taking the full height from the panel top (`UF-02`, without repeating `<Project> / <File>`), showing `< New chat / Shared` + `[AI]` + `[↗]` + `•••`, a `#26354A` banner, `"What's next?"`, 3 expandable suggestion groups (`Tidy and polish`, `Generate designs`, `Create plugins and shaders`), a `>_ Terminal` pill (embedding the VT100 PTY `claude`/`codex`/`grok`/`$SHELL` directly) and an `"Ask for changes"` input with a `#0D99FF` border (`UF-05`). 2. While on `Agents`/`Assets`/`Variables`/`Tools`/`Specs`, 1 click on `File` on the Left Rail immediately returns the Left Side Panel to `Pages & Layers` (`UF-01`); only a second click on `File` collapses/expands the left sidebar. 3. When switching `Design | Prototype | </>` on the Bottom Toolbar (`UF-03`) or switching `Home <-> Multi-Tab` (`UF-04`), the Right Inspector and each project tab's state sync instantly 1:1.

## 5. Edge cases
- No chat history yet (`empty`): Show the `"What's next?"` hero with 3 expandable suggestion groups (`Tidy and polish`, `Generate designs`, `Create plugins and shaders`).
- Agent processing a request (`loading`): Show a progress indicator on the `[AI]` pill and stream output directly in the inline `>_ Terminal` frame.
- CLI command or `NodeSpec` syntax error (`error`): Show a red `#F24822` message right in the `Agents` Side Panel without losing the text being typed in the `"Ask for changes"` input.
- Empty command input (`disabled`): Disable the round `↑` send button while the `"Ask for changes"` input is empty to avoid sending an empty prompt.
