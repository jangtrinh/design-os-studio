## 1. User Story
As a **Product Owner, Developer and QA Engineer**, I want to read the Spec Format v2 package directly through 5 Role Views (`PO View`, `Dev View (US & AC)`, `QA & Coverage`, `Wireframes & UI Contract`, `Gates & Canvas`) and click `Copy for AI` on each item, so that I can check `REQ -> US -> AC -> SCN -> Screen` traceability coverage and send precise requests to the AI Agent.

## 2. Flow
- Entry condition: The user opens `RailItem::Specs` (`S02`) in DESIGN:OS Studio.
- Main flow: 1. Choose a Spec v2 package in the left sidebar. 2. Read the Attention Line and 4-Metric KPI Strip at the top of the page. 3. Switch between the 5 Role Views (`PO View`, `Dev View`, `QA & Coverage`, `Wireframes & UI Contract`, `Gates & Canvas`). 4. Click `Copy for AI` on a User Story or AC to copy a standard Markdown citation block to the clipboard.

## 3. Data and rules

| ID | Rule | Source |
|---|---|---|
| **BR-02** | The Reader v2 UI uses the Operate dark palette (`#16171B`, `#1F2024`, `#26272C`, `#2E2F36`), never uses emoji in UI chrome and never nests cards inside cards. | [contract](../contract/FC-001.md) D2 |
| **BR-03** | The four KPI cards (`Requirements & Stories`, `Acceptance & Scenarios`, `Screen States & UI Contract`, `Pipeline Gates G1–G5`) take their numbers directly from the same loaded Spec model. | [contract](../contract/FC-001.md) D3 |
| **BR-04** | The `Copy for AI` button generates exactly the format with `File: <path>:<start>-<end>`, `Item: <US-id> › <title>`, `Reader page: Dev View`, `Project: design-os-studio` and stores it in `state.last_ai_copy`. | [contract](../contract/FC-001.md) D4 |

## 4. Acceptance Criteria

| ID | Given | When | Then | Scenario |
|---|---|---|---|---|
| AC-01 | The `plans/specs/designos-studio-v2/` or `product-os-spec-driven` folder exists on disk | The user opens Spec Reader `S02` | The Reader loads `spec.manifest.json`, `PRD.md`, `US-01..03.md`, `ui-contract.md`, `review/gates/*.md` in full and shows the 4-Metric KPI Strip with no number drift. | SCN-02-01 |
| AC-02 | The user is on the `Dev View (US & AC)` tab viewing a User Story or AC row | The user clicks the `Copy for AI` button | The clipboard and `state.last_ai_copy` receive a Markdown citation block with the correct file path, `:start-end` line range, US/AC item, reader page name and project. | SCN-02-02 |
| AC-03 | At least one Gate is `PENDING` or one item is `OPEN` | The user looks at the top of `S02` | The Attention Line clearly shows the Gate awaiting review with a `Review Gate` action button that jumps straight to `Gates & Canvas`. | SCN-02-03 |

## 5. Edge cases
- Empty (`empty`): When the Spec package only has the legacy v1 format (`brainstorm.md`, `usecases.md`, `plan.md`), automatically synthesise equivalent data into the 5 tabs without an error.
- Error (`error`): When a Markdown or JSON file in the package is missing, show a `MISSING` status badge next to that item instead of crashing the reader.
- Long content (`long-content`): Cells in the `PRD`, `AC` and `ui-contract.md` tables are safely truncated (`elide`) within their column and never overflow the frame.
