## 1. User Story
As a **QA Automation Engineer & AI Subagent**, I want to run **`design`:os studio** screenshot and UI test commands entirely in the background (`with_visible(false).with_active(false)`), so that all 13 screens `S01..S13` and the 16 Retina 2x visual proof images (`docs/screenshots/*.png` via `scripts/capture-visual-proof.sh`) are automatically verified at 99%+ similarity to Figma UI3 without ever taking window focus or interrupting the user's screen.

## 2. Flow
- Entry condition: An AI agent or CI process needs proof screenshots for Gate `G4` / `G5` and the 16-image `docs/screenshots/*.png` library on the user's macOS machine.
- Main flow: 1. Call the CLI `designos --screenshot <out.png>` with a screen/panel flag (`--panel`, `--menu`, `--popover`, `--dev-mode`, `--home`) or run `scripts/capture-visual-proof.sh`. 2. The app starts with `ViewportBuilder::default().with_visible(false).with_active(false)` (or renders offscreen), builds all layout frames and writes Retina 2x PNG files to disk. 3. Compare the result images with the Figma UI3 reference images and update the `CURRENT` proof in Gate `G4` / `G5`, `README.md` (12-Section AI-Ready README) and `docs/index.html` (9-Tier GitHub Pages).

## 5. Edge cases
- Empty (`empty`): When `--screenshot` runs without an input file path, automatically load the sample document (`demo_document`) so a valid test image is always produced.
- Error (`error`): When the `--screenshot` target directory does not exist or is not writable, return a non-`0` exit code with a clear error message on `stderr`.
- Timeout (`loading`): Exit the process automatically as soon as the target frame has been rendered and written to disk, never leaving a hung background process.
