## Scope tasks
1. **#161 Shadow blend modes (S / P1).** Add `blendMode` to drop and inner shadows in the model, CPU paint (`paint.rs`, `designos-render`), GPU (`designos-gpu`), `.fig` import/export (`fig.rs`, `fig_export.rs`), REST import (`rest_import.rs`) and the Effects panel (`panels/effects.rs`).
2. **#162 Effect caps (S / P2).** In `panels/effects.rs`, cap the + control per effect type (8 drop / 8 inner / 1 layer blur / 1 background blur). UI only: imported data is never trimmed (Law 1).

## Acceptance criteria
- **AC-161-1** A multiply drop shadow darkens the backdrop at a literal pixel (expected value asserted).
- **AC-161-2** `.fig` and REST round trips keep the blend mode.
- **AC-161-3** Files without a blend mode load as Normal.
- **AC-161-4** CPU and GPU render the same pixels for every supported blend mode (within the existing tolerance).
- **AC-162-1** With 8 drop shadows, the + for a 9th is disabled and shows a tooltip; the same for the 8/1/1 limits of the other types.
- **AC-162-2** An imported file with more effects than the caps keeps all of them, renders them, and saves them back unchanged.

## Test steps
1. Unit pixel test: a multiply shadow over a known backdrop; assert the literal pixel value. Run on CPU and GPU and compare.
2. Round trip: import a `.fig` fixture with multiply/screen shadows, export, re-import; assert `blendMode` unchanged. Repeat via REST import.
3. Load a pre-v0.7.4 file; assert every shadow reads Normal and renders unchanged.
4. Shell test: add drop shadows up to 8; assert the + control is disabled with the tooltip. Repeat for inner, layer blur, background blur.
5. Import a fixture with 12 drop shadows; assert 12 remain after load, render and save.
6. QA smoke: desktop capture at 1440 for the Effects panel (blend mode picker, disabled + with tooltip) attached to each PR.

## Edge cases
- Blend modes the renderer doesn't support yet: keep the value on round trip and fall back to Normal for display only; never drop it.
- Inner shadow + blend mode on a layer with children knockout (#520 F2): blend must apply after the knockout.
- Shadow on a group with `PASS_THROUGH` vs a non-pass-through layer blend.
- Over-cap file: deleting effects until under the cap re-enables +; the panel must not auto-trim.
- Undo/redo of blend mode changes and of adding an effect at the cap.
- Mixed selection with different blend modes shows "Mixed".
