## Deliberate deviation (controller or owner to accept)

The issue says the message should match the MCP `INSTANCE_CYCLE` text. That text is code-prefixed, differs per path and carries no loop (`... (cycle)`), so it never matched across paths. The GUI wording follows the issue's own example and ux-writing rule 5 (lead is 7 words, plus the loop). Same facts, no code. The loop can be long for deeply nested mains (Card → Icon → Row → Card); the loop is the information the issue asks for.

"Drag a main into its own instance": no refusal exists. The drop resolves to the page (instances are not drop targets), so nothing to explain. I wrote that test, saw no guard fire, and removed it.
