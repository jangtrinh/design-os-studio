Five layers, one window.

Studio opens your .fig file in a native window. The canvas draws it on the GPU, the Layers panel and the inspector edit it, and the Agents rail lets a coding agent work on it with you.

  1. The .fig fileRead and written natively. This one, the Untitled UI PRO v8.0 kit, has 208,610 nodes.
  2. CanvasDrawn on the GPU with wgpu. When nothing changes for a quarter second, it draws one full-quality frame.
  3. LayersPages and layers, as the file has them.
  4. InspectorDesign, Prototype and Dev Mode, with code in 7 targets.
  5. Agents railClaude Code, Codex and Antigravity in a terminal beside the canvas.

01 Figma

Bring your Figma in.

  • Paste from Figma desktop. Press Cmd+V on the canvas. Images come along.
  • Read and write .fig files. Open a Figma file, edit it, save it back.
  • Styles travel with the file. A .fig file brings its effect and grid styles with it.

02 Agents

Let an agent build with you.

  • 22 tools through designos-mcp. Built-in presets for Claude Code, Codex and Antigravity.
  • Edits replay as node operations. Agents wait while you drag or edit text, then the edit lands.
  • Every agent edit is its own undo. The new layer is selected and your view stays where it was.

03 Code

Ship the code.

  • Dev Mode prints 7 targets: CSS, Tailwind, React, SwiftUI, UIKit, Compose and Android XML.

Questions.

What is DESIGN:OS Studio?

A native desktop design editor written in Rust. It draws on the GPU with wgpu, opens and saves Figma .fig files, and bundles a local server so coding agents can edit the open document.

Can I use my Figma files?

Yes. Studio opens and saves .fig files. You can also copy layers in Figma desktop and paste them onto the Studio canvas with Cmd+V. They land centered in the view as one undo step, images included.

How do coding agents work with it?

Studio bundles designos-mcp, a local MCP server with 22 tools. Studio has built-in presets for Claude Code, Codex and Antigravity. Agent edits replay into your open document, wait while you drag, and each one is its own undo step.

Which systems does it run on?

macOS, Windows and Linux. Releases are verified on macOS; Windows and Linux builds are tested by users. On a Mac, the first launch needs Open Anyway once.

What is the license?
