Let an agent build with you.

Studio bundles designos-mcp, a local server with 22 tools. Point your coding agent at it and it works on the document you have open.

  • Edits replay into your document.They land as node operations, so the rest of a large file stays intact.
  • Agents wait while you work.An edit holds while you drag or edit text, then lands.

Questions.

What is DESIGN:OS Studio?

A native desktop design editor written in Rust. It draws on the GPU with wgpu, opens and saves Figma .fig files, and bundles a local server so coding agents can edit the open document.

Can I use my Figma files?

Yes. Studio opens and saves .fig files. You can also copy layers in Figma desktop and paste them onto the Studio canvas with Cmd+V. They land centered in the view as one undo step, images included.

How do coding agents work with it?

Studio bundles designos-mcp, a local MCP server with 22 tools. Studio has built-in presets for Claude Code, Codex and Antigravity. Agent edits replay into your open document, wait while you drag, and each one is its own undo step.

Which systems does it run on?

macOS, Windows and Linux. Releases are verified on macOS; Windows and Linux builds are tested by users. On a Mac, the first launch needs Open Anyway once.

What is the license?

MIT or Apache-2.0, your choice. The source is on GitHub.
