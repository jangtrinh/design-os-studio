### Installing **design:os studio**

Download the installer for your platform below. Every package includes all 4 tools (`designos-studio`, `designos`, `designos-mcp`, and `designos-diff`):

- **macOS (Apple Silicon & Intel Universal):**
  - Download `designos-<version>-macos.dmg`, open it, and drag **designos.app** to **Applications**.
  - *(Optional)* Double-click `install-cli.command` inside the DMG to clear the macOS quarantine attribute and symlink `designos-studio`, `designos`, `designos-mcp`, and `designos-diff` onto your `PATH`.
- **Windows (x64):**
  - **GUI Installer:** Download and run `designos-<version>-x86_64-pc-windows-msvc-setup.exe` (per-user install, no Administrator prompt required; creates Desktop & Start Menu shortcuts and registers `.designos` / `.fig` files).
  - **Portable ZIP / PowerShell:** Unzip `designos-<version>-x86_64-pc-windows-msvc.zip` and run `powershell -ExecutionPolicy Bypass -File .\install.ps1`.
- **Linux (x64):**
  - **Ubuntu / Debian (`.deb`):** `sudo apt install ./designos_<version>_amd64.deb`
  - **Any Linux distro (`.tar.gz`):** Unpack `designos-<version>-x86_64-unknown-linux-gnu.tar.gz` and run `./install.sh` (installs under `~/.local`, no `sudo` needed).

Full instructions: [docs/install.md](https://github.com/jangtrinh/design-os-studio/blob/main/docs/install.md). Verify downloads against `SHA256SUMS` or `release-manifest.json`.
