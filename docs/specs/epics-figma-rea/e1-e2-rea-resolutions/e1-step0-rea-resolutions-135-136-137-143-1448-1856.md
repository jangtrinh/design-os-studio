## Answer first

- **Extended Variable Collections (`#135`)**: Resolved via Kiwi node types `VARIABLE_SET = 31` and `VARIABLE_OVERRIDE = 35`. Extended collections reference immediate parents via `backingVariableSetId = 377` and root collections via `rootVariableKey = 386`. Modes explicitly map parent modes via `parentVariableSetId = 4` and `parentModeId = 5`. Overrides store `overriddenVariableId = 464` and `variableDataValues = 315`. Reset deletes the override record, restoring fall-through inheritance `[FACT - seen]`.
- **Document Color Profile (`#136`)**: Resolved via `DocumentColorProfile` enum (`LEGACY = 0`, `SRGB = 1`, `DISPLAY_P3 = 2`, tag `349`). Colors in `.fig` are stored directly as un-premultiplied floats $[0..1]$ in the active document color space. Switching via **Convert** applies a $3\times 3$ chromatic adaptation matrix; **Assign** retains raw floats while re-interpreting gamut boundaries `[FACT - seen]`.
- **AuthoredColor & Dev Mode CSS (`#137`)**: Resolved via `AuthoredColor` message (tag `44` on `Paint`, tag `56` on `Effect`, `space = 1`, channels `c0..c4`). Channel mapping: OKLCH ($L, C, H, \alpha$), OKLAB ($L, a, b, \alpha$), Display P3 ($R, G, B, \alpha$). Dev Mode emits CSS functions `oklch(...)`, `oklab(...)`, and `color(display-p3 ...)` `[FACT - seen]`.
- **Text Style Overrides & Reapply (`#1448`)**: Resolved via `styleIdForText = 334` and `isOverrideOverTextStyle = 376`. In-place overrides are strictly permitted for font weight/italic, text decoration, and hyperlinks; editing font size, family, or spacing clears `styleIdForText`. "Reapply text style" strips all `isOverrideOverTextStyle` entries `[FACT - seen]`.
- **Component Prop Def Variable Bindings (`#1856`)**: Resolved via field `varValue = 9` on `ComponentPropDef` and `varValue = 3` on `ComponentPropAssignment`, storing `VariableData` with an alias GUID `[FACT - seen]`.
- **Prototype Timing/Easing Variables (`#143`)**: Resolved via `transitionDurationVar = 46` and `easingVar = 47` on `PrototypeAction`, plus tags `5` and `6` on `BehaviorTransition` `[FACT - seen]`.

## 1. What could NOT be verified (read first)

1. **Simultaneous Cross-Collection Deletion Cascade:** How Figma behaves when a parent collection mode is deleted while an extended child collection mode points to it was not observable directly in static JS/WASM. Studio's resolver falls back to the collection's default mode if `parentModeId` is dangling `[INFERENCE]`.
2. **Display P3 Rendering on Non-P3 Displays:** In headless Linux or standard sRGB macOS setups, `wgpu` surfaces are bound to `Bgra8UnormSrgb` or `Rgba8Unorm`. Whether Figma renders P3 to sRGB via tone-mapping or simple gamut clamping is inferred as standard linear clamping `[INFERENCE]`.
3. **Compound Transitions with Mixed Variables:** Whether a prototype interaction can simultaneously bind a variable to duration and a hardcoded bezier easing was seen (`transitionDurationVar` and `easingVar` are independent fields), but conflict resolution when the variable evaluates to a negative number was not seen; Studio clamps duration $\ge 0.0$ `[INFERENCE]`.

#### TypeScript Plugin API Specification `[FACT - seen: plugin-api.d.ts lines 12052-12075]`
```ts
interface ExtendedVariableCollection extends Omit<VariableCollection, 'addMode'> {
  readonly isExtension: true
  readonly parentVariableCollectionId: string
  readonly rootVariableCollectionId: string
  readonly variableIds: string[]
  readonly variableOverrides: {
    [variableId: string]: {
      [extendedModeId: string]: VariableValue
    }
  }
  removeOverridesForVariable(variableToClear: Variable): void
  readonly modes: Array<{
    modeId: string
    name: string
    parentModeId: string
  }>
  removeMode(modeId: string): void
}
```

#### Resolution Algorithm
Given variable $V$ and target mode $M$ in collection $C$:
1. If $C$ contains a local `VARIABLE_OVERRIDE` where `overriddenVariableId == V.id` and has an entry for mode $M$, return that overridden value.
2. If $C$ is an extended collection (`backingVariableSetId.is_some()`), lookup mode $M$'s `parentModeId` $M_{\text{parent}}$ in parent collection $P$.
3. Recursively invoke resolution for $V$ under mode $M_{\text{parent}}$ in parent collection $P$.
4. Terminate when reaching root collection $R$ (`backingVariableSetId == None`). Return $R$'s mode value for $V$.

### 2.2 #136 Display P3 Document Color Profile

#### Kiwi Schema & Profile Tags `[FACT - seen: figma-real-schema.txt lines 2208, 4312-4318]`
```kiwi
Enum DocumentColorProfile
    LEGACY = 0
    SRGB = 1
    DISPLAY_P3 = 2

Message NodeChange
    colorProfile = 341 : ColorProfile
    documentColorProfile = 349 : DocumentColorProfile
```

#### Storage Format & Color Space Math
- **Float Storage:** All `Color { r, g, b, a }` floats in `.fig` are stored in the active document's primary chromaticities.
- **Chromatic Adaptation Matrix (sRGB to Display P3):**
  Using standard D65 adapted primaries:
  $$\begin{bmatrix} R_{\text{P3}} \\ G_{\text{P3}} \\ B_{\text{P3}} \end{bmatrix} = \begin{bmatrix} 0.822462 & 0.177538 & 0.000000 \\ 0.033194 & 0.966806 & 0.000000 \\ 0.017083 & 0.072397 & 0.910520 \end{bmatrix} \begin{bmatrix} R_{\text{sRGB}} \\ G_{\text{sRGB}} \\ B_{\text{sRGB}} \end{bmatrix}$$
- **Convert vs. Assign:**
  - `convert-document-color-profile-display-p3`: Multiply all existing node/paint floats by $M_{\text{sRGB} \to \text{P3}}$, preserving visual appearance.
  - `assign-document-color-profile-display-p3`: Leave floats unchanged, setting `documentColorProfile = DISPLAY_P3`. Saturation expands to full P3 gamut.
- **PNG Export:**
  - For `DISPLAY_P3`: Write standard 16-byte `cHRM` chunk (White point $x=0.3127, y=0.3290$; Red $x=0.680, y=0.320$; Green $x=0.265, y=0.690$; Blue $x=0.150, y=0.060$) and `iCCP` chunk with Display P3 profile name `[FACT - seen]`.

### 2.3 #137 AuthoredColor & Dev Mode CSS

#### Kiwi Schema `[FACT - seen: figma-real-schema.txt lines 490-504, 1258-1259]`
```kiwi
Enum ColorSpace
    SRGB = 0
    DISPLAY_P3 = 1
    HEX = 2
    HSL = 3
    HSB = 4
    OKLAB = 5
    OKLCH = 6
    CMYK = 7

Message AuthoredColor
    space = 1 : ColorSpace
    c0 = 2 : Float
    c1 = 3 : Float
    c2 = 4 : Float
    c3 = 5 : Float
    c4 = 6 : Float

Message Paint
    authoredColor = 44 : AuthoredColor
    authoredStops = 45 : AuthoredColorStop[]
```

#### Channel Layouts:
- `OKLCH`: $c_0 = L \in [0, 1]$, $c_1 = C \in [0, 0.4]$, $c_2 = H \in [0, 360]$, $c_3 = \alpha \in [0, 1]$.
- `OKLAB`: $c_0 = L \in [0, 1]$, $c_1 = a \in [-0.4, 0.4]$, $c_2 = b \in [-0.4, 0.4]$, $c_3 = \alpha \in [0, 1]$.
- `DISPLAY_P3`: $c_0 = R \in [0, 1]$, $c_1 = G \in [0, 1]$, $c_2 = B \in [0, 1]$, $c_3 = \alpha \in [0, 1]$.

#### Dev Mode CSS Emission Rules:
- If `space == OKLCH`: `oklch(L C H)` or `oklch(L C H / alpha)`.
- If `space == OKLAB`: `oklab(L a b)` or `oklab(L a b / alpha)`.
- If `space == DISPLAY_P3`: `color(display-p3 r g b)` or `color(display-p3 r g b / alpha)`.
- If `space` in `HEX | SRGB | HSB | HSL`: Default hex `#RRGGBB` or `rgba(r, g, b, a)`.

### 2.4 #1448 Text Style Overrides & Reapply

- **Kiwi Field:** `NodeChange::styleIdForText = 334 : StyleId` links the text layer to a `TextStyle`.
- **Override Flag:** Overridden runs in `NodeChange::styleOverrideTable = 3` are flagged with `isOverrideOverTextStyle = 376 : Bool = true`.
- **Permitted Overrides:**
  - Font weight / italic style.
  - Text decoration (underline / strikethrough).
  - Hyperlinks.
- **Detaching Overrides:** Modifying font size, line height, letter spacing, font family, or binding a variable to font size or family clears `styleIdForText` (unlinks style).
- **Reapply Command:** "Reapply text style" removes all entries in `styleOverrideTable` marked `isOverrideOverTextStyle`, resetting spans to uniform master style values `[FACT - seen]`.

### 4.4 CSS Dev Mode Emission: `crates/designos-export/src/css.rs`
```rust
pub fn format_paint_color(paint: &Paint, profile: DocumentColorProfile) -> String {
    if let Some(authored) = &paint.authored_color {
        match authored.space {
            AuthoredColorSpace::Oklch => {
                return if authored.c3 < 1.0 {
                    format!("oklch({:.3} {:.3} {:.1} / {:.2})", authored.c0, authored.c1, authored.c2, authored.c3)
                } else {
                    format!("oklch({:.3} {:.3} {:.1})", authored.c0, authored.c1, authored.c2)
                };
            }
            AuthoredColorSpace::Oklab => {
                return if authored.c3 < 1.0 {
                    format!("oklab({:.3} {:.3} {:.3} / {:.2})", authored.c0, authored.c1, authored.c2, authored.c3)
                } else {
                    format!("oklab({:.3} {:.3} {:.3})", authored.c0, authored.c1, authored.c2)
                };
            }
            AuthoredColorSpace::DisplayP3 => {
                return if authored.c3 < 1.0 {
                    format!("color(display-p3 {:.3} {:.3} {:.3} / {:.2})", authored.c0, authored.c1, authored.c2, authored.c3)
                } else {
                    format!("color(display-p3 {:.3} {:.3} {:.3})", authored.c0, authored.c1, authored.c2)
                };
            }
            _ => {}
        }
    }
    // Fallback to hex or rgba:
    format_standard_color(paint.color(), profile)
}
```
