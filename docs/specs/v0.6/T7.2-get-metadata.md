## 1. Summary and user story

As an agent, I get a compact outline of a frame or page (ids, names, types, computed bounds, hidden
and in-progress flags, lint issue counts) in a few hundred tokens, then fetch detail only where I need
it.

## 2. Current state (FACT)

- Reads today: `designos_list_nodes` returns flat summaries by id order (`crates/designos-mcp/src/engine.rs:57-79`,
  summary fields `engine.rs:542-546`: id, name, kind, parent, child count, visible, local x/y, size);
  `designos_get_node` returns one full node (`engine.rs:80-83`). There is no tree outline and no
  page-space bounds.
- World transforms: `Document::world_transform` (`crates/designos-doc/src/lib.rs:608`).
- XPath type names: `xpath_type_name` (line 9-26 of the legacy module in `crates/designos-doc/src/`).

## 3. Behaviour rules

1. Root: `node_id`, or `page_id`, or the session's default page (`resolve_default_page`,
   `engine.rs:30-35`).
2. Depth-first, children in paint order (the `children` order). Depth 0 is the root. `depth`
   (1..=10, default 3) limits descendants; a node with children beyond the limit gets
   `children="<count>"` and `more="depth"`.
3. Node budget: `max_nodes` (1..=5,000, default 1,000). When reached, the current element closes with
   `more="budget"` on every unvisited parent, and the reply sets `truncated: true` with
   `remaining_estimate` (sum of known child counts not emitted).
4. Element name = lower-case XPath type (`frame`, `text`, `instance`, `component`, `component-set`,
   `section`, `group`, `rectangle`, `ellipse`, `vector`, `boolean-operation`, `line`, `polygon`,
   `star`, `page`, ...).
5. Attributes (omitted when default): `id`, `name` (XML-escaped), `x`, `y`, `width`, `height` (page
   space, after layout is settled, rounded to 0.01), `rotation` (degrees, when non-zero),
   `hidden="true"`, `locked="true"`, `layout="row|column|grid"` on auto-layout frames,
   `component="<name>"` and `variant="Size=lg, State=hover"` on instances, `in-progress="<run id or
   'yes'>"` (E15-7), `issues="<n>"` (3.6), `text="<first 40 chars>"` on text nodes.
6. Hidden nodes are included and flagged (`hidden="true"`), with their subtree, unless
   `include_hidden: false` (then omitted and counted in `hidden_omitted`).
7. Lint counts (E15 extension): `issues` is the number of non-ignored findings for that node in the
   session's lint cache at the current document revision. With `lint: true`, the tool first runs E15-9
   `lint_subtree` with preset `agent` over the emitted nodes (50 ms budget), filling the cache. Without a
   cache entry the attribute is omitted (unknown, not zero).

## 4. Data model / schema changes

- `designos_export::agent_context::metadata_xml(doc, root, &MetadataOptions, lint_counts:
  Option<&dyn Fn(NodeId) -> Option<u16>>) -> MetadataXml` is pure, so Studio (which depends on
  designos-export but not on designos-mcp at runtime, `crates/designos-app/Cargo.toml:29-59`) can build
  the same outline for E15-16.
- Session lint cache: `HashMap<NodeId, u16>` keyed by document revision (E15-5 `Engine.revision`),
  filled by `designos_lint`, the issues block (E15-12) and `lint: true`; cleared when the revision
  changes for the affected subtrees (simplest correct version: whole cache cleared on any revision
  change).
- No document change.

## 5. Contracts

Tool `designos_get_metadata` (`readOnlyHint:true, idempotentHint:true`):

```json
{"type":"object","additionalProperties":false,"properties":{
  "node_id":{"type":"integer","minimum":1},"page_id":{"type":"integer","minimum":1},
  "depth":{"type":"integer","minimum":1,"maximum":10,"default":3},
  "max_nodes":{"type":"integer","minimum":1,"maximum":5000,"default":1000},
  "include_hidden":{"type":"boolean","default":true},
  "lint":{"type":"boolean","default":false}}}
```

Output: `content[0]` text = the XML; `structuredContent`:

```json
{"root_id":12,"xml":"<frame id=\"12\" name=\"Pricing\" x=\"0\" y=\"0\" width=\"1440\" height=\"900\">...</frame>",
 "node_count":214,"truncated":false,"remaining_estimate":0,"hidden_omitted":0,"lint_ran":false}
```

Errors: `NODE_NOT_FOUND`, `EXACTLY_ONE_SCOPE` (node_id and page_id both set), `VALUE_OUT_OF_RANGE`.

## 8. Edge cases

1. Names with `<`, `&`, quotes, control characters: escaped; control characters replaced by U+FFFD.
2. Instance children: emitted like any subtree (they are real nodes); `component` names the main
   component (or the library name when it is a library copy).
3. Scoped Studio canvas (`crates/designos-app/src/live_canvas_scope.rs:1-14`): empty frame shells
   report `children="0"`; the reply adds `scoped: true` when the page holds shells, so the agent knows
   it is not seeing everything.
4. Root is a page with 10,000 top-level frames and depth 1: budget stops at 1,000 with `truncated`.
5. Text with only whitespace: `text` attribute omitted.
6. Node whose layout is pending: layout is settled first (`Engine::call` already does,
   `engine.rs:40`).

## 9. Non-goals

- Full node properties (use `designos_get_node`).
- Streaming pagination (E15-17 owns cursors for queries).

## 11. Performance budgets

O(emitted nodes); ≤ 5 ms for 1,000 nodes. World bounds computed by carrying the parent affine down the
walk, not by calling `world_transform` per node. With `lint: true`, at most 50 ms extra.

## 12. Dependencies and build order

them are added in those PRs if they land later).
