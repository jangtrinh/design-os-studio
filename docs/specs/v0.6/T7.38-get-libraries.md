## 1. Summary and user story

As an agent, I see which design libraries this file can use: its own local assets, the libraries it
has enabled (with version and whether an update exists), and the published libraries it has not
enabled (flagged, not hidden), each with component, style and variable counts.

## 2. Current state (FACT)

- Per-document library state: `LibraryState { published, enabled: Vec<LibraryRef{id, name, version}>,
  external }` (`crates/designos-doc/src/library.rs:21-66`).
- Published libraries on this device: `Library::list_libraries() -> Vec<LibraryIndex>` with
  `components`, `styles`, `variables` counts of the latest version and `versions`
  (`crates/designos-library/src/publish.rs:38-66`, `179`); snapshots load with `load_snapshot`
  (`publish.rs:199`). The library root is `$DESIGNOS_LIBRARY` or the platform data dir
  (`crates/designos-library/src/store.rs:188-196`).
- designos-mcp already depends on designos-library (`crates/designos-mcp/Cargo.toml:16`) but has no
  library tool.
- Local assets of the open document: `publishable_assets(doc)` (`crates/designos-doc/src/library_ops.rs:245`).

## 3. Behaviour rules

1. Library root: `$DESIGNOS_LIBRARY` (Studio sets it in the agent environment to its own root), else
   `Library::default_root()`. Missing or unreadable root: the tool still returns the local entry and
   `library_root_error` with the reason (never fails the call).
2. Entries:
   - `local`: this document's own components (incl. sets), styles and variables, counted with
     `publishable_assets`; `published` info when the file is itself published.
   - each published library in the root: `origin: "library"`, `enabled` (present in
     `doc.library.enabled`), `enabled_version` (from `LibraryRef.version`), `latest_version`,
     `update_available` (`latest > enabled_version`), counts from `LibraryIndex`.
   - enabled libraries missing from the root (file moved or deleted): `origin: "library"`,
     `missing: true`, counts from the local copies in `doc.library.external`.
3. Disabled libraries are listed with `enabled: false` (flagged, not hidden).
4. Order: local first, then enabled (by name), then disabled (by name).
5. `library_source.rs` provides `enabled_snapshots(doc) -> Vec<LibrarySnapshot>` (latest enabled
   version, cached per session by `(id, version)`), reused by E15-1, E15-3 and T7.9.

## 4. Data model / schema changes

None persisted. Session cache `HashMap<(String, u32), Arc<LibrarySnapshot>>`.

## 5. Contracts

Tool `designos_get_libraries` (`readOnlyHint:true, idempotentHint:true`), input `{}`.

Output:

```json
{"libraries":[
  {"id":"local","name":"This file","origin":"local","enabled":true,
   "components":42,"styles":18,"variables":120,"published":null},
  {"id":"lib-7f3a","name":"Brand kit","origin":"library","enabled":true,"enabled_version":3,
   "latest_version":4,"update_available":true,"components":210,"styles":40,"variables":300,"missing":false},
  {"id":"lib-91c0","name":"Icons","origin":"library","enabled":false,"latest_version":2,
   "components":800,"styles":0,"variables":0,"missing":false}],
 "library_root":"/Users/me/Library/Application Support/designos/library","library_root_error":null}
```

Errors: none beyond `INVALID_ARGUMENTS` (unknown fields).

## 8. Edge cases

1. Library published from this very file and also enabled in it: listed once as `local` with
   `published` set; not repeated as a library.
2. Corrupt `index.json`: entry with `error` and no counts; other entries unaffected.
3. Two libraries with the same name: both listed; ids differ.
4. Empty root (fresh install): only `local`.
5. Enabled version newer than any published version (index rolled back): `update_available: false`,
   `version_mismatch: true`.

## 9. Non-goals

- Enabling, disabling or updating libraries from MCP.
- Remote or team libraries (out of product by nature, R4.14).

## 10. Test plan

Seam: MCP test with a temporary library root (`DESIGNOS_LIBRARY` set to a temp dir) and two published
fixture libraries.

| Case | Expected |
|---|---|
| `lists_every_library_with_counts` | 3 entries (local, enabled, disabled) with origin and counts equal to the indexes |
| `disabled_flagged_not_hidden` | disabled library present with `enabled: false` |
| `update_available_flag` | enabled v1, latest v2 → `update_available: true` |
| `missing_enabled_library` | enabled id absent from root → `missing: true` |
| `unreadable_root` | root path is a file → local entry plus `library_root_error` |

## 11. Performance budgets

Reads only `index.json` files (no snapshots) for the listing: ≤ 20 ms for 50 libraries. Snapshot
loading (for E15-1/T7.9) is lazy and cached.
