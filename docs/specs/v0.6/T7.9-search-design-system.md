## 1. Summary and user story

As an agent about to build a screen, I search "button", "primary color" or "heading" and get ranked
components, styles and variables from this file and its enabled libraries, already in the exact form I
can paste into `apply_spec` (component reference, variant property schema, slot definitions, `var:`
and `style:` paths).

## 3. Behaviour rules

### 3.1 Corpus

Local document assets plus every enabled library snapshot (T7.38 `enabled_snapshots`). Disabled
libraries are excluded (acceptance 2). Each item: kind (`component`, `component_set`, `style`,
`variable`), name, description, origin (`local` or library name and id), and for variables the
collection name and kind.

### 3.2 Ranking

Query is split into lower-case tokens (whitespace, `/`, `-`, `_`). Score per item:
- exact full-name match (case-insensitive): +100;
- name starts with the query: +60;
- every query token appears in the name path segments: +40; each token found in the description: +10;
- token fuzzy match (Levenshtein ≤ 1 for tokens of length ≥ 4) in name: +15;
- local items +5 (prefer the file's own system), library items +0;
- variables whose scopes do not allow the requested `property` (when given): excluded.
Ties: kind order (component_set, component, style, variable), then name. Items with score 0 are
dropped. `limit` 1..=50, default 20.

### 3.3 Instance-ready payload (E15 extension)

- Components and sets: `ref` = the E15-1 component reference string that resolves uniquely
  (`"node:<id>"` for local, the library key for library assets, never an ambiguous name);
  `variant_properties` = `{name: [options...]}` with the set default; `properties` (Boolean, Text,
  InstanceSwap definitions with defaults); `slots` = slot definitions with `min_children`,
  `max_children`, `strict` and `recommended` (each recommended component as a `ref`).
- Variables: `ref` = `"var:<collection>/<name>"` (or `var:id:<id>` when the path is ambiguous, per
  E15-3), resolved value per mode, `code_syntax`.
- Styles: `ref` = `"style:<name>"`, style type and a value summary.
- Each result carries `example`: a minimal NodeSpec fragment using `ref`
  (`{"kind":"instance","component":"<ref>","variant":{...defaults}}`, `{"fill":"var:..."}`,
  `{"text_style":"..."}`) that applies without edits.

## 5. Contracts

Tool `designos_search_design_system` (`readOnlyHint:true, idempotentHint:true`):

```json
{"type":"object","required":["query"],"additionalProperties":false,"properties":{
  "query":{"type":"string","minLength":1,"maxLength":256},
  "kinds":{"type":"array","items":{"enum":["component","style","variable"]}},
  "property":{"type":"string","description":"Bindable property key to filter variables by scope, e.g. fills/0, itemSpacing."},
  "limit":{"type":"integer","minimum":1,"maximum":50,"default":20}}}
```

Output:

```json
{"results":[
  {"kind":"component_set","name":"Button","origin":{"type":"library","id":"lib-7f3a","name":"Brand kit"},
   "score":160,"ref":"a1b2c3",
   "variant_properties":{"Size":{"options":["sm","md","lg"],"default":"md"},"State":{"options":["default","hover"],"default":"default"}},
   "properties":[{"name":"Label","type":"text","default":"Button"}],"slots":[],
   "example":{"kind":"instance","component":"a1b2c3","variant":{"Size":"md","State":"default"}}},
  {"kind":"variable","name":"Primary","collection":"Color","origin":{"type":"local"},"score":45,
   "ref":"var:Color/Primary","values":{"Light":"#0D99FF","Dark":"#3582FF"},"example":{"fill":"var:Color/Primary"}}],
 "total":2,"libraries_searched":["local","lib-7f3a"]}
```

Errors: `INVALID_ARGUMENTS`; `UNKNOWN_PROPERTY_KEY` when `property` is not a bindable key
(`valid_options` from `property_kind` keys).

## 8. Edge cases

1. Same component name local and in a library: both returned; local ranks higher (+5).
2. Library copy already imported locally: returned once, as the library asset with `local_copy:
   "node:<id>"`.
3. Component set with 300 variants: `variant_properties` lists property options, not every variant.
4. Query matching only a description: low score but returned.
5. Hidden-from-publishing variables in a library: excluded (they are not published).
6. Empty enabled list and no local assets: `results: []`, `total: 0`.

- Semantic or embedding search (no bundled model, R4.13).
