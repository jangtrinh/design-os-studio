# Figma Engine vs. DESIGN:OS Studio Engine Architecture

This document explains how Figma's production C++/WebAssembly/WebGPU engine scales to 100k–1M+ node enterprise files (such as `VSF - PCP.fig`: `723,136` Kiwi records / `112,474` scene nodes on the 7-page benchmark, `1,082,324` scene nodes across all 31 pages) and how each subsystem maps to **DESIGN:OS Studio** (`design-os-studio`) across **Phase 1 (Completed 2026-10-14)** and the **Phase 2 Roadmap**.

## 2. Deep Dive: How Each Mechanism Works in `design-os-studio`

### 2.1 Kiwi Binary Schema vs. Compact Native Format (`.designos` / `.designos`)
- **Figma (`.fig`):** Uses Evan Wallace's **Kiwi** binary format (`crates/designos-fig/src/kiwi.rs`) inside a ZIP/Zstd container (`crates/designos-fig/src/container.rs`). Every node change is a compact bit-packed struct with optional field presence flags, while vector geometry (`fillGeometry`, `strokeGeometry`, `vectorNetworkBlob`) is stored as packed IEEE-754 float/byte buffers.
- **DESIGN:OS Studio (Phase 1):**
  - Previously, `Document::to_json` used `serde_json::to_string_pretty`, serializing every `u8` of every PNG image as a separate newline-indented integer (`4–5 bytes/byte`) and emitting 18 default/empty fields on every `Node`. On `VSF - PCP.fig` (`112,474` scene nodes / `723,136` Kiwi records), this produced a **`6.8 GB`** file on disk.
  - Now (`crates/designos-doc/src/lib.rs`, `node.rs`), `Document::to_json` emits single-line JSON, skips all default/empty fields via `#[serde(default, skip_serializing_if = "...")]`, and encodes `Document::images` via `serde_images` as compact `"hex:..."` strings while retaining a dual-mode deserializer that transparently reads both `"hex:..."` and legacy `[u8]` arrays.

### 2.2 Retained Scene Graph, `SceneIndex`, and Hit-Testing
- **World-Bounds Cache (`crates/designos-render/src/index.rs`):**
  - `SceneIndex::ensure(doc, page, rev)` walks the active page once per `(page, rev)` and computes every node's world `Affine` transform, world bounding box `(x0, y0, x1, y1)` (including stroke and shadow margins), and ancestor clip chain.
- **Pre-Resolve GPU Frustum & Sub-Pixel Culling (`crates/designos-gpu/src/compile.rs`):**
  - In `Ctx::draw_children`, before calling `board::get(doc, *cid)` or `resolve_node(doc, &child)`, the compiler checks `raw.visible` and projects `self.index.bounds_of(*cid)` into device pixels (`bb`).
  - If `!hits(bb, vis)` (outside viewport/clip) or `interactive && (bb.2 - bb.0) < 0.75 && (bb.3 - bb.1) < 0.75` (sub-pixel at current zoom), the node and its entire subtree are skipped in nanoseconds with zero allocations.
- **Spatial Hit-Testing (`crates/designos-app/src/canvas/hit.rs`):**
  - `hit_test_with_index` and `deep_hit_test_with_index` query `SceneIndex::bounds_of(cid)` to prune entire off-cursor branches in $O(\text{depth})$ during mouse move and click events.

### 2.3 `egui-wgpu` Metal Staging Buffer Safety & Interactive LOD Guard (`interactive()`)
- **Why Metal Crashed Before Phase 1:**
  - On a 112,474-node (723,136 Kiwi records) benchmark zoomed out to fit-to-screen, hundreds of frames with `clips_content = true`, `opacity < 1.0`, or `DropShadow`/`LayerBlur` effects each opened a recursive offscreen GPU `Program` (`self.new_prog(rect)`), allocating thousands of uniform buffers and dynamic vertex uploads inside a single `egui-wgpu` `prepare()` callback and overflowing Metal's staging buffer.
- **How Phase 1 Solves It (`crates/designos-gpu/src/compile.rs`, `geom.rs`, `crates/designos-app/src/canvas/gpu.rs`):**
  1. **`interactive()` Guard:** `fn interactive(&self) -> bool { self.cull && self.geom.budget.is_some() }` is `true` ONLY for the live desktop viewport (`budget = Some(8ms)`) and `false` for all headless tests (`budget = None`).
  2. **Text Greeking (`< 3.5px`):** In `draw_body_inner`, when `interactive` and a `NodeKind::Text` node's screen height is `< 3.5px`, it draws a lightweight translucent `unit_rect` bar (`1.25px..3.5px`) or skips (`< 1.25px`), bypassing `cosmic-text` shaping and `lyon` glyph tessellation.
  3. **Hardware Scissor Clip Fallback & Offscreen `Program` Cap (`< 64`):** Axis-aligned rectangular frames with small screen-space corner radii (`max_r_px <= 2.5` or `self.progs.len() >= 32`) use `wgpu` hardware scissor rectangles (`narrow_clip`) instead of rasterizing an offscreen `mask_clip` texture. Offscreen `Program` creation for masks, layer opacity, blends, and effects is capped at `self.progs.len() < 64`.
  4. **Cumulative 8ms Tessellation Budget (`frame_build_nanos`):** `GeomCache::get` accumulates actual `build_geom` elapsed nanoseconds across the frame. Once `frame_build_nanos >= 8_000_000` (8ms), uncached `Text`/`Vector`/`BooleanOp` nodes return an empty placeholder for the current frame and increment `stale_hits`, triggering `ui.ctx().request_repaint()` so complex pages stream in smoothly across frames without ever freezing the main thread.
  5. **Idle `FrameKey` Reuse:** When `(page, rev, offset, zoom, dpr, size, font_gen)` is unchanged and `stale_hits == 0`, `canvas::gpu::paint` submits `Cb { frame: None }`, reusing the existing `Output` texture at **`0.0%` idle CPU**.
